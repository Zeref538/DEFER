DEFER

Document Evidence and Fixed Explicit Rules

Hand a language model a document, ask a question the document answers, and it may answer from what it memorised instead. This is a fine-tune that makes it trust the page — and admit when the page doesn't answer at all.

Every answer below is real

This page runs no model. Each answer was generated once, logged, committed, and is replayed here exactly as recorded — so the demo cannot quietly disagree with the study. The passages are genuine Wikipedia paragraphs with one fact edited, which is what makes the trap fair: there is exactly one correct answer, and it is the one on the page.

The four numbers, always together

A single number would flatter this. A model can score perfectly on "admits when it doesn't know" by refusing everything — so the last column counts how often it refuses questions the passage plainly answers. Read them as a set or not at all.
